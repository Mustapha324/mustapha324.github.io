# Mustapha Strachan Portfolio

Static personal portfolio site for Mustapha Strachan, a Computer Science student at the University of Central Florida.

## Run locally

Open the root-level `index.html` in a browser, or serve the repository root with any simple static-file server.

## Updating content

Edit `index.html` for project, experience, and contact information. The stylesheet is `assets/css/main.css`. The published résumé is `assets/resume/Mustapha-Strachan-Resume.pdf`.

Project links point to public repositories. Only add a live demo when its URL has been confirmed.
